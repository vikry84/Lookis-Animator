# 🎨 Lookis - Free 2D Drawing & Animation Software

![Lookis Banner](https://via.placeholder.com/1024x300?text=Lookis+2D+Animation+Software) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](http://makeapullrequest.com)

**Lookis** is a brand new, completely free, and open-source 2D drawing and animation software designed for creators, animators, and storytellers. Whether you are creating traditional frame-by-frame animation, storyboards, or digital illustrations, Lookis provides a lightweight but powerful environment to bring your ideas to life.

## ✨ Key Features

* **Xsheet Timeline (Traditional Animation Workflow):** Inspired by industry-standard tools like OpenToonz, Lookis uses an Xsheet (Exposure Sheet) timeline. This allows for precise timing, lip-syncing, and frame organization, perfect for traditional 2D animators.
* **100% Free & Open Source:** No subscriptions, no hidden fees. Lookis is built for the community, by the community.
* **Intuitive 2D Drawing Engine:** Fast and responsive drawing tools, including customizable brushes, pen pressure support, and vector/bitmap layering.
* **Lightweight & Fast:** Optimized to run smoothly on various hardware configurations without lagging during heavy frame playback.
* **Multi-Format Export:** Easily export your finished animations to MP4, GIF, or image sequences (PNG/JPG).

## 🚀 Getting Started

### Installation
*(Tambahkan instruksi instalasi di sini. Contoh:)*
1. Download the latest release from the [Releases page](../../releases).
2. Run the installer for your OS (Windows/macOS/Linux).
3. Open Lookis and start animating!

### Building from Source
If you want to contribute or build the app yourself, follow these steps:
```bash
# Clone the repository
git clone [https://github.com/username/lookis.git](https://github.com/username/lookis.git)

# Navigate to the directory
cd lookis

# Install dependencies (Sesuaikan dengan bahasa/framework yang Anda gunakan)
npm install # atau pip install, cmake, dll.

# Run the application
npm start
